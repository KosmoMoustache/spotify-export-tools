# Spotify Playlist Export tools

[Sockseek](https://github.com/fiso64/sockseek)

## 1. Check which tracks are missing from Navidrome

```bash
python check_navidrome.py --url <subsonic compatible url> --username <username> --password <password> --format <flac|mp3|m4a|...>
```

Writes `results.txt` (FOUND / MISSING / FORMAT-MISMATCH).

## 2. Generate the download list for sldl/sockseek

```bash
just generate                 # missing only  -> sldl_tracks.csv
just generate-all             # + format mismatch -> sldl_all-var.csv
```

## 3. Download with sockseek

Config: `sockseek/sockseek.conf` (credentials, flac preference, output dir).

```bash
just preview                  # dry run, lists tracks
just run                      # download missing tracks into sockseek/downloads
just run-all                  # also re-download format-mismatch tracks
```

## 4. Sync a playlist to Subsonic/Navidrome

Creates or updates a playlist on a Subsonic server so its tracks match a Spotify
CSV export, in CSV order. Unresolvable tracks are resolved interactively
(pick a candidate / search again / skip / abort).

```bash
uv run sync_playlist.py --csv spotify_playlists/My_Playlist.csv \
    --url http://localhost:4533 --username <user> --password <pass> \
    [--playlist-id <id> | --playlist-name "My Playlist"] \
    [--dry-run] [--auto-skip]
```

- Without `--playlist-name`/`--playlist-id`, the CSV file stem is used as the
  playlist name (created if missing).
- `--dry-run` resolves every track and prints the plan without touching the server.
- `--auto-skip` skips not-found tracks without prompting (for scripts/CI).

Restrict the search to specific Subsonic music libraries (folders):

```bash
uv run sync_playlist.py --csv ... --list-libraries      # list libraries and exit
uv run sync_playlist.py --csv ... --library "Rock"      # by name or id (repeatable)
uv run sync_playlist.py --csv ... --library-select      # interactive checkbox
```
