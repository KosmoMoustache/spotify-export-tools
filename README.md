# Subify - Spotify export tools

[Sockseek](https://github.com/fiso64/sockseek)

Should work on any Subsonic-compatible server (I've successfully used it with Navidrome).

## Usage

Get your Spotify playlist as a CSV export (I've used [Exportify](https://exportify.net/)).

### Requirements

- uv
- [just (optional)](https://github.com/casey/just)

Then run the following commands

### Credentials

You can authenticate with your server using either

- a config file `creds.txt` by default, `--config` to override (url,username, password)
- environment variables (`NAVIDROME_URL`, `NAVIDROME_USER`, `NAVIDROME_PASSWORD`)
- or command line arguments (`--url`, `--username`, `--password`).

Command line arguments take precedence over environment variables, which take precedence over the config file.

### 1. Check your connection with your server

```bash
uv run subify.py test
or 
just test
```

### 2. Check which tracks are missing from your Subsonic server

```bash
uv run subify.py check
or 
just check
```

Generates a `results.txt` with the list of tracks that are FOUND, MISSING, or have a FORMAT-MISMATCH (default: flac). When a track isn't found, it will prompt for user input (can be disabled with `--auto-skip`).

### 3. You can generate a download list for [Sockseek](https://github.com/fiso64/sockseek)

```bash
uv run subify.py sockseek
or 
just sockseek
```

### 3b. Generate MISSING and FORMAT-MISMATCH lists

```bash
uv run subify.py wish
or 
just wish
```

Writes two files: `missing.txt` with one `TITLE ARTIST` per line for tracks
not found on the server, and `format-mismatch.txt` with one
`TITLE ARTIST flac` per line for tracks found with a different audio format
(the expected format is appended; override with `--format`).

By default it parses the results generated by `check` (`check-results.txt`) and
makes no server calls, so run `check` first. Pass `--from-results <file>` to
use a different results file, or `--force-scan` to scan the server directly
(ignoring the results file).

### 4. Sync your Spotify playlist to your Subsonic server

```bash
uv run subify.py sync 
or 
just sync
```

Sync `Liked_Songs.csv` using the Library ID 2 to a playlist called "Spotify - Titres likés" on your Subsonic server. With credentials of creds2.txt. Auto skipping the use prompt.

```bash
 uv run subify.py sync --library 2 --playlist-name "Spotify - Titres likés" --config creds2.txt --auto-skip --dry-run 
```
